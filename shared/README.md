# shared/

Code every app depends on. `theme.css` holds the design tokens and component styles;
`engine.js` holds the `MathLab` global — random helpers, the algebra term parser, the quiz
shell and score persistence.

| File | What |
|------|------|
| `engine.js` | `MathLab`: quiz shell, scoring, the learning log, reusable answer UIs (choice with named mistakes, keypad fields) |
| `algebra.js`, `problems.js` | The expression engine and question repertoire behind Step Builder |
| `linear.js` | `Linear`: exact fractions, lines, pairs of equations, substitution/elimination step scripts with traps, typed-equation parser |
| `grid.js` | `Grid`: tappable coordinate plane — snaps to grid points, shows coordinates above the finger |
| `stories.js` | `Stories`: nine word-problem families, many skins, all built backwards from the answer |
| `all-apps.js` | GENERATED by `tools/bundle.mjs` — every app's registration, for the daily mix. Do not edit |

Goes here: anything two or more apps need.
Does not go here: topic-specific question generators — those live with their app.
